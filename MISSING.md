# Missing evidence and framework depth

This file records every known gap that currently needs a fallback. A fallback is part of the output receipt; it is never evidence that the missing input was measured.

| Missing item | Current fallback | What closes it | Impact |
| --- | --- | --- | --- |
| Fitted coefficients for the bundled smoke run | Values labelled `FAKE` and `literature_estimate`, with uncertainty 0.8 | Joint trait-and-outcome data, a held-out fit, and a versioned evidence-table entry | Smoke outcomes prove plumbing and determinism only; they do not predict people |
| Measured population for Northport and Southport | A 1,200-row `FAKE` population with explicit place totals and simple age defaults | Census or licensed microdata reweighted to dated marginals | Agent traits and network structure are illustrative |
| Shared-atlas population wired into generic run generation | Run DSL population references remain separate from the city organizer | A versioned population bundle compiler that reads promoted atlas observations and IPF weights | Real atlas coverage does not automatically make a run simulation-ready |
| Full action/media/network coupling inside the numeric tick | Pure, tested action, conflict, chain, media, and sparse-network modules; smoke runtime advances declared state transitions | A vector execution planner that compiles DSL rules into mass transition kernels and spotlight logs | The interfaces are operational, while emergent cross-module behavior remains thin |
| Real individual histories for mass agents | Deterministic representative projection from recorded place counts; the UI labels the projection `FAKE` or representative | Weighted agent-state persistence or statistically exact cohort tracking per tick | Clicking a mass row proves the drill-down contract, not a fully persisted personal causal history |
