# Bundled reference data

`countryInfo.txt` is the GeoNames country information table used to map ISO country codes to names, populations, and canonical Petraterrium regions.

- Source: <https://download.geonames.org/export/dump/countryInfo.txt>
- Retrieved: 2026-10-26
- Licence: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- Attribution: GeoNames geographical database
- SHA-256: `c55f638cfaafb4fe45a9aa15120a0f1f78e8a34a8e1847d7b9320cf740fbc9ab`

The file is committed because it is a small public reference table required during test collection and runtime region resolution.

`registry_feature_dump/` contains the compact registry dump generated by `backend/scripts/build_registry_dump.py`. UN WPP 2024 contributes 2023 single-year age, sex, and population records for 237 countries or areas and eight directly covered canonical regions. The 47-person Rest / unassigned region uses the global WPP age and sex distribution as an explicit imputation, so all nine canonical regions have a distribution. Exact ages run from 0 through 100+; no age-band feature is created.

The dump also contains distributions for the other 18 canonical features across the ten largest countries by population and all canonical region records. The source pack uses World Bank WDI, UN DESA household data, ILOSTAT, WVS Wave 7, the Global Preferences Survey, OpenPsychometrics IPIP responses, and published Schwartz culture-level values. Each distribution retains its method, evidence status, date, uncertainty, source version, and population count. Population-weighted regional aggregates and explicit estimates remain labelled imputed; they are never presented as direct measurements. MBTI is a label-only exploratory proxy and cannot become a predictor.

The manifest pins source URLs, hashes, licences, mappings, row counts, and coverage. Restricted respondent-level WVS data, IPUMS microdata, other large source archives, and the runtime SQLite database remain ignored. `source_inventory.json` records unavailable or restricted sources and the exact action needed to replace each fallback.

`uv run python scripts/load_cities.py` installs this dump after loading cities500. `uv run python scripts/build_registry_dump.py --install-shared` rebuilds from the pinned official sources and installs the resulting version explicitly.
